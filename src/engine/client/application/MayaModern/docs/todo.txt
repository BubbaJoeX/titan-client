## Build Requirements
- Maya 2027 (64-bit) - https://www.autodesk.com/developer-network/platform-technologies/maya
- Maya 2027 Devkit - at D:\titan\lib\Maya2027\devkitBase (include/ + lib/) or set MAYA_LOCATION
- Visual Studio 2022 (17.8.3+) or VS Insiders (see build-mayamodern.ps1)
- CMake 3.13+
- Configure: .\build-mayamodern.ps1 or cmake -B build -A x64
- FindMaya checks: MAYA_LOCATION, C:\Program Files\Autodesk\Maya2027, D:\Program Files\Autodesk\Maya2027
- NVIDIA Texture Tools (nvtt_export.exe) for static mesh / shader DDS publish

### ANS / animation behavior (recent)
- [x] Rotation keyframes: delta quaternion path aligned with legacy exporter expectations
- [x] Import prep: clear keys + bind pose restore; skip hardpoints (hold_* / swgHardpointParent) from cutKey/dagPose and from anim application
- [x] Joint rotation order: MFnTransform::rotationOrder() (MTransformationMatrix enum) was cast to MEulerRotation's enum - every XYZ joint was converted as YZX (SwgAnimMath::eulerOrderOf)
- [x] Deltas composed in engine space (rotate = mirror(delta * bind)), static rotations included (SwgAnimMath.h)
- [x] importSkeleton records the skeleton bind per joint (swgBindRotate / swgBindTranslate); import resets and export measures deltas from it (export no longer treats the first frame as bind)
- [x] Import keys every whole frame with the engine's slerp between file keys (linear Euler curves drifted far from the engine between sparse CKAT keys)
- [x] importAnimation re-applies the clip's fps + range after Maya's file import restores the scene's (keys had landed on 0.8-frame steps)
- [x] Export: playback range only (no default 0-200 padding), skeleton joint names (root, not root__all_b_l0), redundant keys dropped (0.0015 rad / 0.5 mm)
- [x] importSkeletalMesh: skin bound before blend targets; targets added with blendShape -frontOfChain (body/head skins were left unbound)
- [x] Verified: stock CKAT -> export -> reimport within 0.0015 rad / 0.5 mm on every joint and frame (SwgMayaMCP examples/ans_roundtrip.py); authored test clip examples/make_test_animation.py
- [ ] Export CKAT (compressed) - KFAT only today
- [ ] Customisable body shaders: hum_m body/head get no shading group on import

### Pipeline Workflow
1. **Import** - Load SWG assets (mesh, skeleton, animation, materials)
2. **Edit** - Modify in Maya (hardpoints, blend shapes, geometry, materials)
3. **Export** - Write back to SWG IFF format (translators + export* commands)
